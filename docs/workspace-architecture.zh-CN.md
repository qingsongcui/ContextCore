# Senrelay 个人 Agent 工作台

一个人可能用多个 Agent 完成同一件事。项目保留工作现场，个人资产记录可复用的能力，Agent 名片让另一个人判断可以委托什么。桌面应用与本机网页共用这套结构。

## 当前页面与入口

| 用户要做的事 | 入口 | 下一步 |
| --- | --- | --- |
| 今天继续工作 | 工作台 `?page=home` | 进入最近更新的活动项目，或先创建项目、接入记录 |
| 查看一个项目 | 项目 `?page=projects` | 先读当前记忆，按需查看依据、进度、资料或原始对话 |
| 跨项目沿用习惯 | 我的 Agent → 个人记忆 `?page=personal&section=memory` | 阅读、补充、纠正个人工作约定 |
| 说明自己擅长什么 | 能力与作品 `?page=personal&section=assets` | 从项目选依据，记录个人与 Agent 的贡献，整理可复用方法 |
| 让别人认识自己 | Agent 名片 `?page=personal&section=profile` | 选择作品、核对预览，保存或导出 |
| 就一件具体事情合作 | 协作 `?page=exchange` | 选名片上的一项能力，填写交付与条件，核对后导出 |
| 管理执行环境 | 管理 → Agent 管理、用量与性能、设置 | 接入、配置、用量分析、备份及变更记录 |

窄屏使用可收起的导航。旧项目、对话、记忆和宿主链接继续进入相应对象。工作台仅概览已获准展示的名片内容。协作导出使用保存后的名片版本，当能力被移出时，用户需要重新选择。

## 云端接入后各对象的归属

| 上游条件 | 对应页面如何生长 | 完成后用户可以做什么 |
| --- | --- | --- |
| 可选账户、设备绑定、名片版本和可见范围 | 名片增加发布、更新与撤回，工作空间可切换身份 | 将选定的资料交给可识别的接收者 |
| 双方身份、邀请和权限 | 协作增加联系人、收件箱和委托状态 | 两个 Agent 发起、接受、退回和验收一次任务 |
| 成员角色、项目级访问和交付版本 | 项目增加团队空间、分工、依赖及验收 | 跨团队协作，按项目授予与撤销访问 |
| Skill 版本、许可和交付，有偿服务的订单与结算 | 能力与作品可选上架，名片提供服务入口 | 对方可取得方法，或委托一次结果 |
| 可复现的运行与验收数据 | 管理中的执行记录可支撑同任务比较 | 按质量、成本和人工介入选择方案 |
| 稳定的委托对象、访问范围和事件 | 管理增加开发者应用与授权 | 软件可提交任务、接收事件和获取获准结果 |

本分支的协作交付物是用户自行传递的本地文本；导出不会创建账号、发送委托或触发扣款。对话接力继续由接收方在自己的 Agent 内发起。

## 本地数据与跨 Agent 分发

| 页面或操作 | 本机数据及实际结果 |
| --- | --- |
| 项目记忆、个人记忆 | 从当前有效的记忆读模型读取决定、个人约定、来源和替代历史。项目中尚未确认的提议不会遮盖有效的个人约定。 |
| 能力与作品、名片 | 保存到带修订号的个人档案；选择依据时核对证据版本。名片导出只读取用户选中的可展示字段。 |
| 个人方法 → 全局 Skill | 在已保存的作品里补全输入、步骤、输出，预览即将加入库的 SKILL.md。确认后生成可单独编辑的全局定义；更新前可以对照库内原文。该操作只写资源库。 |
| 协作说明 | 可保存多个本机草稿，重开、更新或删除。导出前服务端重新核对保存的名片与选项。能力被撤选后用户可重新选择，手写的交付与条件仍保留。 |
| 全局资源库 | 从侧栏或 Agent 管理进入；Skill、MCP、使用规则均可在此维护。也支持选择宿主、预览并导入已有资源。是否参与分发、覆盖哪些配置，单独由用户确认。 |
| 批量分发 | 先选资源和支持该类型的宿主，预览目标、版本与文件变更，再执行安装、更新或移除。每个目标的更改计划、回执和批次历史保存在本机。失败后可单独重新预览，成功的目标无需重复执行。 |
| 配置目录 | 服务商、模型、账号定义和项目配置方案保留各自的使用范围。目录中的可见范围、实际写入宿主的配置和宿主运行时加载是三个独立状态。 |

全局在此指同一台设备上该 Senrelay 工作区可管理的配置。测试安装包独立保存资源和宿主配置。需要核对实际写入位置时，查看批次预览列出的文件路径。原生配置由用户明确选择后导入，通用账户条目和凭据授权分别管理。
