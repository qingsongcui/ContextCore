# 中英文双语（i18n）

适用对象：`app/frontend`（产品工作台）与 `website`（Senrelay 官网）。

## 1. 按钮位置与交互

| 界面 | 位置 | 形态 |
|---|---|---|
| 产品工作台（桌面） | 左侧栏底部，设置按钮与主题切换之间 | `中 / EN` 两段式按钮，带语言图标 |
| 产品工作台（移动端） | 顶部栏右侧，品牌之后 | 同上，紧凑模式隐藏图标 |
| 官网（首页与指南页） | 页头右侧，GitHub 按钮之前；移动端保持可见 | `中 / EN` 两段式按钮 |

交互约定：

- 点击即切换，不刷新页面、不改变当前页面或项目。
- 当前语言按钮 `aria-pressed="true"`，另一侧为 `false`。
- 按钮组 `aria-label` 随语言变化（语言 / Language），按钮自身保留 `lang="zh-CN"` 与 `lang="en"`。
- 切换后 `document.documentElement.lang`、页面标题、meta、结构化数据同步更新。

## 2. 语言状态与默认策略

存储键：

- 产品：`localStorage["contextcore.language"]`
- 官网：`localStorage["senrelay.website.language"]`

优先级从高到低：

1. URL 参数 `?lang=zh` 或 `?lang=en`：仅影响本次打开，便于分享与验收。
2. 已保存的语言偏好。
3. 浏览器首选语言 `navigator.languages[0]`：`zh*` → 中文，其他 → 英文。
4. 兜底中文。

点击语言按钮会写入 `localStorage`，并移除 URL 中的 `lang` 参数，避免下次打开被旧链接覆盖。

## 3. 缺失英文时的处理

产品与官网都以**中文原文作为字典 key**，英文缺失时自动回退中文，不会出现空白或报错。

- 产品：`t()` 在英文模式下找不到 key 时返回中文原文，开发环境在控制台提示一次。
- 官网：缺失的文本节点保留中文，并在父元素标记 `data-i18n-missing="<中文>"`，便于定位。
- **构建检查会直接失败**，不允许把缺失文案带到发布版本：
  - `app/frontend/scripts/check-i18n.mjs`
  - `website/scripts/check-i18n.mjs`

## 4. 翻译范围

**产品工作台**

- 页面：左侧主导航固定为三项，依次为项目工作台（`projects`）、Agent 管理（`agents`）、用量与性能（`usage`），并在存在未决冲突时按需显示待确认（`conflicts`）；侧栏底部紧凑控制区包含设置（`settings`，内嵌变更记录 `audit` 与增强检索设置）、语言切换（`中 / EN`）与主题切换（浅色 / 深色 / 跟随系统）。
- 侧栏、页头、标签页、按钮、筛选器、空状态、加载状态、错误提示、确认弹窗、冲突处理、连接与写入授权、知识资料导入与版本恢复。
- 无障碍文案（`aria-label`、`title`、`placeholder`）与日期格式（`zh-CN` / `en-US`）。

**官网**

- 页面区域：首屏（Hero）、为什么（The Reason）、接棒指引与六项清单（The Handoff）、共享记忆（The Shared Memory）、我的助手（Your Assistant, Your Choices）、开始流程（Workflow）、工具接入（In Your Own Tools）、常见问题（FAQ）、本地运行指南（Run Guide）、结尾与开始指引（Closing/Start）、页脚（Footer）。
- 元数据：<title>、description、Open Graph、Twitter Card、JSON-LD、og:locale、canonical、robots 与 llms.txt 辅助文件。
- 交互与无障碍：语言切换按钮、状态说明、提示语与无障碍标签（aria-label、role="img" 等）。

**不翻译（有意保留）**

- 用户产生的项目名、聊天正文、记忆内容、标签。
- 产品名、Agent 名称、模型名、记录 ID。
- 后端返回的未知错误原文；前端已知错误通过字典翻译，未知内容原样显示。
- 英文装饰标签（如 `PROJECT CONTEXT`、`CONNECTED, NOT ASSUMED`），属于视觉系统。
- 技术标识 `ContextCore`、MCP 工具名、文件路径。

## 5. 校验与验证

```bash
# 产品
cd app/frontend
npm run check:i18n
npm run typecheck
npm run lint
npm run build

# 官网
cd website
npm run build
npm run check
npm run check:i18n
npm run check:brand
npm run check:interactions
```

检查内容：

- 产品：所有提取的中文 key 全部提供英文翻译（具体数量以 check:i18n 报告为准，当前为 1,334 条文本）；英文值不含中文；{placeholder} 两侧一致；源码不存在未包裹的中文 JSX 文本或模板字符串。
- 官网：所有静态文本节点、CJK 属性、HTML 覆盖块（htmlEn）与元数据字段（metaEn）全部提供英文翻译（具体数量以 website check:i18n 报告为准）；英文值不含中文；语言按钮、持久化与 brand 配置一致性受 check:brand 与 check:interactions 约束。
- 运行时：使用 DOM/测试环境挂载验证默认中文、点击 EN 切换语言、设置页/各区域无未翻译中文残留、点击中文恢复，以及 ?lang=en 直接进入英文。

已知限制：静态 HTML 默认输出中文，英文用户首次打开会先看到中文再切换；官网在未设置 `SITE_URL` 时默认输出 `noindex` 本地预览，配置正式 `SITE_URL` 构建后自动开启索引与 `canonical`/`sitemap.xml`。产品后端返回的未知错误仍为中文原文。
