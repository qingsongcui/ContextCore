macOS AI 编程助手管理与 MCP 配置 — Senrelay 续境

在一台 Mac 上管理 Claude Code、Codex、Cursor 等六类 AI 编程助手。导入受支持的原生配置，预览 MCP、Skills、规则和供应商变更。

更新于 2026-11-19 · Senrelay 维护者

六个助手，一份共享资源库

Senrelay 的 Agent 管理页包含 Claude Code、Codex、Cursor、Antigravity、Oh My Pi（OMP）和 OpenCode。CLI、桌面端等入口按所属助手归组。你可以复用一份 MCP、Skill、规则或供应商定义，并选择写入哪些助手的原生配置。查看 Claude Code、Cursor 与 Codex 的 MCP 配置路径。

默认使用同一份用户配置时，Codex CLI 和桌面端在同一个配置视图管理。CLI 设了独立的 CODEX_HOME 时分别处理。Antigravity 的桌面端与 CLI 共用受支持的 MCP 和 Skills 路径，规则文件按入口分别管理。Codex 官方配置参考。

如何同步 Claude Code、Cursor 和 Codex 的 MCP 配置？

  1. 在 Agent 管理中选定来源助手，打开「读取原生配置」，选择 MCP，核对将导入的条目。
  2. 在「共享资源」选中准备分发的定义和目标助手，逐一预览文件差异，确认后应用。有凭据的资源在目标端需要可用的本机绑定。
  3. 核对写入后的文件，在目标助手中重新加载并查看工具列表。遇到冲突时检查外部改动，并可用更改记录中的快照预览恢复。

同一个 MCP 条目已经存在时，可根据预览选择接管受支持的原生配置。需要核对 JSON 和 TOML 写法时，先看 MCP JSON 与 TOML 示例。

如何切换 Claude Code、Codex 或 OpenCode 的模型供应商？

选择助手后，在「模型与账号」手动添加服务商，选用内置预设，或预览导入原生配置。核对模型、接口协议与账号后应用，随后在助手里确认实际加载。配置变更可从更改记录撤销。Cursor 的 API Key 与模型仍在 Cursor Settings → Models 中设置。Claude Code 配置和优先级 · OpenCode 服务商文档 · Cursor API Key 文档。

受支持的本机路由可配置首选与备用线路，或用模型别名聚合多个服务商。真实调用、重试和已知用量可在 AI 编程用量页面 核对。

常见问题

需要 CC Switch 才能管理助手吗？

Senrelay 可独立运行。从已选助手的原生配置、Senrelay 预设或手动定义开始，就可以在共享资源库中配置并应用变更。

能共享 Claude Code 和 Codex 的 Skills 吗？

可以。选择已导入的 Skill 和目标助手，预览写入范围后应用。可按受支持的安装模式部署，最终加载应在各助手中分别核对。

配置备份能带走账号密钥吗？

Senrelay 的配置备份默认省略密钥和授权会话。恢复前可核对差异，需要密钥的定义恢复后再连接本机钥匙串或重新授权。

适用版本与资料

以上适用于 macOS 14.0 及以上的 Apple Silicon Mac，以及 Senrelay v1.0.0-beta.7 的 Agent 管理页。各助手的原生功能和写入范围以支持矩阵为准。Beta.7 发布记录与安装包 · 发布版配置管理说明 · Senrelay 安装指南。

Six coding agents, one resource library

Senrelay groups Claude Code, Codex, Cursor, Antigravity, Oh My Pi (OMP), and OpenCode into six workspaces. Reuse a provider, MCP server, Skill, or instruction definition and choose which assistants receive it in their native configuration. See the Claude Code, Cursor, and Codex MCP config paths.

Codex CLI and desktop share a configuration view when both use the default user-level configuration. A separate CODEX_HOME for the CLI is managed separately. Antigravity's desktop and CLI entries share supported MCP and Skills paths, with rules managed per entry. Official Codex configuration reference.

How do I sync MCP configs across Claude Code, Cursor, and Codex?

  1. Open Agent Management, choose the source agent, and review the MCP entries in the native configuration preview.
  2. In Shared Resources, select the definitions and target agents. Review each file diff before applying. Attach local credentials wherever the resource requires them.
  3. Check the written file, then reload the target agent and check its tool list. If a file changed externally, review the conflict and use the change history to preview a restore.

For an existing MCP entry, the preview can show whether its supported native configuration can be taken over. Check the MCP JSON and TOML examples to compare the file formats.

How do I switch providers in Claude Code, Codex, or OpenCode?

Choose a supported agent in Models and Accounts. Add the provider manually, start with a preset, or preview a native import. Confirm the model, API protocol, and account before applying. Check that the agent loaded the change, and use the change history if you need to restore the previous setup. Cursor's API keys and models remain in Cursor Settings → Models. Claude Code settings precedence · OpenCode provider settings · Cursor API key setup.

Supported local routing can use a primary and fallback provider or group models under aliases. To check the provider that handled a request and any retries, open the AI coding usage tracker.

Frequently asked questions

Do I need CC Switch to manage coding agents?

Senrelay runs independently. Start from the selected agent's native configuration, a Senrelay preset, or a manual definition, then review and apply changes from the shared resource library.

Can I share Claude Code and Codex Skills?

Yes. Select the imported Skill and targets, then review the change before applying. Check how each agent loads the Skill after installing with a supported mode.

Do configuration backups include API keys?

Senrelay configuration backups omit secrets and authorization sessions by default. Review the differences before restoring. Reattach Keychain credentials or authorize the account again where required.
