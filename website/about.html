关于 Senrelay 续境 — 作者与产品边界

Senrelay（续境）是运行在 macOS 14.0+（Apple Silicon）上的本机工作台：跨 Agent 对话接力、伴生记忆，以及多宿主 MCP / Skills 配置。MIT 开源，$0，无需注册。

更新于 2026-11-23 · Qingsong Cui（George O'Nair）

作者与仓库

Senrelay 由独立开发者 Qingsong Cui（George O'Nair） 创建并维护。公开身份：GitHub @qingsongcui · X @George_ONair。

源码仓库是 qingsongcui/ContextCore。技术标识仍使用 ContextCore（MCP 服务键 contextcore，回环地址 http://127.0.0.1:8420/mcp/）。公开品牌是 Senrelay · 续境。

与第三方网站 context-core.dev、PyPI 包 contextcore 以及汽车继电器硬件无关。不要运行 pip install contextcore。

产品做什么

在 Claude Code、Codex、Cursor、Antigravity、Oh My Pi、OpenCode 六个核心宿主里输入 /contextcore 或「接力」，从短简介选场、分页读完原文并在新 Agent 上下文里压缩续做。工作台同时管理 MCP、Skills、模型供应商与配置快照。

当前公开版本是 v1.0.0-beta.7。安装步骤见 本地运行指南。价格与许可见 pricing.md（$0 · MIT）。

真实边界

  • 只支持 macOS 14.0+、Apple Silicon（arm64）。不支持 Windows、Linux 或 Intel Mac。
  • 服务只绑定本机回环 127.0.0.1:8420，没有多设备云同步或团队 SaaS。
  • 公开 Beta 为 ad-hoc 签名，首次启动需要 xattr -cr /Applications/Senrelay.app。尚未提供 Apple Developer ID 公证。
  • 9 个扩展宿主只做配置写入，不做会话采集或 /contextcore 接力。

Author and repository

Senrelay is created and maintained by independent developer Qingsong Cui (George O'Nair). Public identities: GitHub @qingsongcui · X @George_ONair.

The source repository is qingsongcui/ContextCore. Technical identifiers remain ContextCore (MCP server key contextcore at http://127.0.0.1:8420/mcp/). The public brand is Senrelay.

It is unrelated to third-party context-core.dev, the PyPI package contextcore, or automotive relay hardware. Do not run pip install contextcore.

What the product does

In the six core hosts — Claude Code, Codex, Cursor, Antigravity, Oh My Pi and OpenCode — type /contextcore or say “relay” to pick a recent session from a short brief, page through the transcript, and compact it in the receiving agent. The workbench also manages MCP, Skills, providers and configuration snapshots.

The current public release is v1.0.0-beta.7. See the local setup guide and pricing.md ($0 · MIT).

Real limits

  • macOS 14.0+ on Apple Silicon (arm64) only. Not Windows, Linux, or Intel Macs.
  • The service binds to loopback 127.0.0.1:8420 only. No multi-device cloud sync or hosted team SaaS.
  • Public Beta builds are ad-hoc signed. First launch needs xattr -cr /Applications/Senrelay.app. Apple Developer ID notarization is not available yet.
  • Only the six supported hosts are covered; other tools are outside the product scope.
