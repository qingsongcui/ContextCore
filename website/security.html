Senrelay 安全说明 — 漏洞私下报告

Senrelay 是单用户本机应用，操作系统用户就是信任边界。安全问题请在 GitHub 私下报告。没有漏洞赏金；本页不是安全认证。

更新于 2026-11-23 · Qingsong Cui（George O'Nair）

如何报告

  1. 普通产品缺陷用 GitHub Issue 模板。不要在公开 Issue 里贴利用细节、凭据、私人对话或数据库导出。
  2. 疑似漏洞请走仓库已开启的 GitHub Private Vulnerability Reporting。若该入口暂时不可用，先向维护者发送不含利用细节的摘要。
  3. 请写明受影响版本、macOS 版本、界面（工作台 / CLI / MCP）、最小合成复现，以及预期与实际边界失败。

完整条款见仓库 SECURITY.md。安装与本机边界见 运行指南。

设计边界（摘要）

  • 服务只绑定回环 127.0.0.1。不要把端口暴露到局域网、反向代理、隧道或公网。
  • 浏览器变更需要会话 Cookie 与对应 CSRF 令牌；Agent 令牌不能代替浏览器管理接口。
  • 这些控制针对网络相邻与跨站威胁；同一 OS 用户下的恶意进程不在隔离范围内。
  • 当前公开支持版本：v1.0.0-beta.6。

没有漏洞赏金计划。文档与单元测试不等于完整的安全认证或新装环境验证。

常见问题

可以把 PoC 发到公开 Issue 吗？

不可以。利用细节、凭据和私人数据只走私下报告。

有赏金吗？

没有。感谢负责任的披露，但目前没有付费赏金。

这能证明安装是安全的吗？

不能。本页描述设计意图与报告渠道，不是对新装机器的认证。

How to report

  1. Use the ordinary GitHub issue template for non-security bugs. Do not post exploit details, credentials, private chats or database exports in a public issue.
  2. For a potential vulnerability, use GitHub Private Vulnerability Reporting, which is enabled on this repository. If that form is unreachable, contact the maintainer first with a non-sensitive summary.
  3. Include the affected version, macOS version, interface (workbench, CLI or MCP), minimal synthetic reproduction, expected behavior and the observed boundary failure.

The full policy is SECURITY.md. Install boundaries: setup guide.

Design boundary (summary)

  • The service binds to loopback 127.0.0.1 only. Do not expose ports to LAN, reverse proxies, tunnels or the public internet.
  • Browser mutations require a session cookie and that session’s CSRF token. Agent tokens cannot replace browser admin CSRF.
  • These controls target network-adjacent and cross-site threats. They do not isolate malicious processes under the same OS user.
  • Currently supported public release: v1.0.0-beta.6.

There is no bug bounty. Documentation and unit tests are not a security certification of a fresh install.

Frequently asked questions

Can I post a PoC on a public issue?

No. Exploit details, credentials and private data belong in a private report only.

Is there a bounty?

No. Responsible disclosure is welcome; there is no paid bounty today.

Does this certify a safe install?

No. This page describes intent and the reporting channel, not certification of a new machine.
