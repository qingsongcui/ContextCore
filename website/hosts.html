Claude Code、Cursor、Codex MCP 配置与六大宿主路径指南

不同编程工具把 MCP 服务器、服务商模型、Skills 与指令规则分别存在 JSON、TOML、JSON5 和 YAML 中，根键名也各不相同。本文列出六个核心上下文宿主的真实磁盘路径与写入保护规则，并说明 Senrelay（续境，GitHub 仓库 qingsongcui/ContextCore）如何做格式转换而不破坏手动注释与密钥。

核对日期：2026-11-15 协议与定价：$0 · MIT 开源（macOS Apple Silicon） MCP 服务键名：contextcore（127.0.0.1:8420/mcp/）

Claude Code、Cursor、Codex MCP 配置怎么找

Claude Code MCP 配置

用户级 MCP 服务在 ~/.claude.json 的 mcpServers 下。与仓库共享的项目级服务写在项目根目录的 .mcp.json。先用 claude mcp list 确认当前项目看到的服务，再在 Claude Code 里用 /mcp 看连接状态。 Claude Code JSON 示例 · Anthropic 文档

Cursor MCP 配置

个人全局配置用 ~/.cursor/mcp.json，仓库级配置用项目中的 .cursor/mcp.json。两者都用 mcpServers，同名服务以项目配置为准。保存后重开 Cursor，在 MCP 管理界面核对服务与工具。 Cursor JSON 示例 · Cursor 文档

Codex MCP 配置

默认在 ~/.codex/config.toml 中，为每个服务使用 [mcp_servers.服务名]。如果 CLI 使用独立 CODEX_HOME，在那个目录查看实际的 config.toml。用 codex mcp list 确认配置，再打开目标入口核对工具是否加载。 Codex TOML 示例 · Codex 文档

先掌握三个配置事实

键名与格式并不通用Claude Code 与 Cursor 用 JSON 里的 mcpServers，Codex 用 TOML 里的 [mcp_servers.*]，OpenCode 用 opencode.json 中的 mcp，Antigravity 的远程服务地址字段叫 serverUrl——不能拿软链接硬套。

只支持六个核心宿主Claude Code、Codex、Cursor、Antigravity、Oh My Pi 与 OpenCode 可接入本地会话索引与 /contextcore 全文接力。实际验收进度见接力验证范围；其他工具不在当前支持范围内。

单机与密钥边界面向 Apple Silicon（arm64）macOS 14.0+，不支持 Windows 或 Linux。API Key 留在 macOS 系统钥匙串中，公开与导出配置时自动剔除密钥。

03 · WRITE GUARDS & DISAMBIGUATION

为什么不该用软链接，以及 Senrelay 如何保证写前安全

格式转换 + 外部手改差异检测

GNU Stow 类软链接会把整个文件绑死在单一格式里，而多款编码助手运行时会自动向配置文件回写遥测或历史索引。Senrelay 在写入前保存时间戳回滚快照；一旦检测到磁盘内容曾在工作台之外被手动改写，会先弹出差异确认窗口再决定覆盖或跳过。

权限分级、Keychain 隔离与预算阻断

读取对话、修改宿主文件与下载可选本地模型三项授权彼此独立；软件启动和配置导入绝不静默篡改用户已安装的 Skill。API Key 独立留在 macOS 钥匙串；向 AGENTS.md / CLAUDE.md 写入受保护规则时若超出预算上限会显式阻断，不会静默截断。

名称与安装源消歧

在命令行或搜索引擎中查找资料时，注意将 Senrelay（续境）（GitHub 仓库 qingsongcui/ContextCore）与互联网上同名的无关第三方项目（如 context-core.dev 平台以及 PyPI 上的 pip install contextcore 包）区分开。在 Apple Silicon Mac 上下载 macOS Beta.7（$0，MIT 协议）。解压并移入应用程序目录后，按下列命令首次启动和检查服务。

# 1. Beta 版本尚无 Apple 公证，手动安装后清理隔离属性
xattr -cr /Applications/Senrelay.app

# 2. 核对本地 MCP 服务端口（桌面常驻版 8420 / 源码开发模式 18420）
curl -s http://127.0.0.1:8420/health

若你在 Windows 或 Linux 下开发，请不要安装 Senrelay——优先使用 Git 仓库内的 AGENTS.md / CLAUDE.md（$0），或参考 5 种方案对比 与 跨 Agent 对话接力实战。

宿主配置常见问题

Senrelay 支持哪些宿主？+

当前只支持 Claude Code、Codex、Cursor、Antigravity、Oh My Pi 与 OpenCode 六个上下文宿主；其他工具不在支持范围内。

OpenCode 的 MCP 配置为什么和其他工具不同？+

OpenCode 的 ~/.config/opencode/opencode.json 使用顶层 mcp 对象，而不是其他工具常见的 mcpServers。

修改过 ~/.codex/config.toml 或 ~/.claude.json 会不会丢手动配置？+

不会。写入前工作台会自动落盘快照支持随时回滚；如果文件在工作台之外被编辑器或 CLI 自行改动过，再次同步时会触发差异对比弹窗，需人工确认差异后才会写回磁盘。

如何在配置文件里确认接对的是 Senrelay 而不是同名包？+

Senrelay（仓库 qingsongcui/ContextCore）统一以 contextcore 作为宿主内的 MCP 键名，指向 http://127.0.0.1:8420/mcp/（不要写成 senrelay-mcp，也不要在 Python 中安装无关的 PyPI 包 contextcore）。

Find your Claude Code, Cursor, or Codex MCP config

Claude Code MCP config

User-scoped servers live under mcpServers in ~/.claude.json. Put project-scoped settings shared through the repository in its root .mcp.json. Run claude mcp list from the relevant project, then check connections with /mcp in Claude Code. Claude Code JSON example · Anthropic docs

Cursor MCP config

Use ~/.cursor/mcp.json for all projects or .cursor/mcp.json inside a repository. Both use mcpServers. When names collide, project settings take precedence. Save and restart Cursor, then check the server and tool list in its MCP interface. Cursor JSON example · Cursor docs

Codex MCP config

The default file is ~/.codex/config.toml, with a [mcp_servers.name] section per server. With a separate CODEX_HOME, look for config.toml in that directory. Run codex mcp list to check the CLI configuration and open the client you use to confirm it loaded the tools. Codex TOML example · Codex docs

Three Key Rules First

No Universal Schema or KeyClaude Code and Cursor expect JSON mcpServers, Codex uses TOML [mcp_servers.*], OpenCode nests under mcp inside opencode.json, and Antigravity names a remote server address serverUrl—making raw symlinks brittle.

Six Supported Hosts OnlyClaude Code, Codex, Cursor, Antigravity, Oh My Pi, and OpenCode can connect to the transcript index and /contextcore relay. See relay verification by host; other tools are outside the supported scope.

Apple Silicon Loopback & KeychainBuilt strictly for Apple Silicon (arm64) macOS 14.0+—not Windows or Linux. API credentials remain in macOS Keychain and are stripped automatically from exports.

03 · WRITE GUARDS & DISAMBIGUATION

Safe Native Translation vs. Brittle Symlinks

Snapshots & External-Edit Diff Checks

Dotfile symlinks collapse across JSON, TOML, YAML, and JSON5—especially when agent clients overwrite runtime fields on startup. Senrelay stores timestamped snapshots before every write and stops to show a diff check whenever manual edits occurred outside the workbench.

Scoped Consent, Keychain Isolation & Budget Guard

Reading transcripts, writing host configs, and downloading optional local models require separate confirmations; startup never overwrites pre-installed host Skills. Secrets stay in macOS Keychain, and protected instruction blocks fail closed when over budget rather than truncating.

Project & Install Disambiguation

When searching online, note that Senrelay (github.com/qingsongcui/ContextCore) is unrelated to third-party projects named context-core.dev or the PyPI package contextcore. Download macOS Beta.7 for Apple Silicon ($0, MIT License), extract it to Applications, then follow the first-launch commands.

# 1. Clear ad-hoc Beta quarantine after moving to /Applications
xattr -cr /Applications/Senrelay.app

# 2. Confirm local loopback service health (desktop 8420 / source dev 18420)
curl -s http://127.0.0.1:8420/health

If your team works on Windows or Linux, skip Senrelay and start with Git-committed AGENTS.md and CLAUDE.md ($0)—or read our 5-way context comparison and cross-agent relay guide.

05 · TROUBLESHOOTING

Host Configuration FAQ

Which hosts does Senrelay support?+

Senrelay supports Claude Code, Codex, Cursor, Antigravity, Oh My Pi, and OpenCode only. Other tools are outside the supported scope.

What are the biggest schema gotchas in OpenCode and Antigravity?+

OpenCode stores servers inside top-level mcp inside ~/.config/opencode/opencode.json instead of mcpServers. Antigravity reads ~/.gemini/config/mcp_config.json and names a remote server address serverUrl rather than url.

Can syncing overwrite manual edits I made in ~/.claude.json or ~/.codex/config.toml?+

Before every write, Senrelay captures a rollback snapshot. If external changes occurred since the last sync, it presents a diff confirmation modal rather than blindly overwriting your edits.

How do I verify my MCP config points to Senrelay instead of an unrelated package?+

Each supported host registers the MCP key contextcore pointing to http://127.0.0.1:8420/mcp/. Never use senrelay-mcp and never run pip install contextcore from PyPI (unrelated project).
