Claude Code 与 Codex 用量统计、Token 和额度 — Senrelay 续境

查看已观测的 Claude Code 与 Codex Token 用量、请求重试和估算费用。区分本机用量、订阅额度、服务商余额与实际账单。

更新于 2026-11-19 · Senrelay 维护者

用量、费用、额度分别怎么查？

Token 用量
按助手、模型或项目查看已观测的输入、输出与缓存 Token。来源是已授权并可解析的原生日志，以及通过 Senrelay 本机路由的调用。没有记录的用量显示未知。
费用估算
按已知计费模型和定价版本计算部分可估算的成本，按币种分开展示。实际扣款以服务商账单为准。
订阅额度与余额
订阅窗口还剩多少、账户余额还有多少，需要去相应来源查询。在「账号额度」中刷新已支持的来源，或打开官方用量页。

如何查看 Claude Code 用量和订阅额度？

在「用量与性能」选 Claude Code 和日期范围，核对已有来源的 Token 和请求。要查 Claude Code 当前订阅窗口与重置时间，在原生 Claude Code 中输入 /usage 或打开官方用量页。Claude Code 官方用量说明。

如何查看 Codex 用量、订阅额度和 API 费用？

在「用量与性能」筛选 Codex，进入「请求」查看已观测的用量。在「账号额度」中选择「读取 Codex 额度」，从当前本机登录的 Codex 账号查询。如果需要核对 OpenAI API 实际费用，查看对应组织的官方 API 用量和账单。OpenAI API 用量面板。

为什么一个请求会有多次尝试？

例如，本机路由先请求首选服务商并收到 429，随后同一请求切到备用服务商并成功。账本显示 1 个逻辑请求、2 次尝试。展开详情可核对失败原因、实际使用的模型、Token 和费用估算。按当前筛选导出 CSV，可以逐条查看尝试。查看助手与服务商配置。

常见问题

用量统计会覆盖每一次 Claude Code 或 Codex 调用吗？

覆盖范围取决于已授权且可解析的日志，以及经过本机路由的请求。查看「来源与定价」中的来源信息，缺少记录时以未知显示。

换算出的费用就是订阅扣款吗？

费用估算根据可观测的 Token 和生效定价计算。订阅额度、API 实际扣费和服务商余额分别查询。

可以查看哪些第三方余额或预算？

已支持使用本机授权查询 DeepSeek 和 Moonshot Kimi 余额及 OpenRouter 的密钥预算。OpenRouter 账户余额另需获权的管理密钥。每项显示查询来源与更新时间。

Where do I check tokens, estimated costs, and quotas?

Token usage
Review observed input, output, and cache tokens by agent, model, or project. Coverage comes from authorized, parsable native logs and requests seen by Senrelay's local routing. Missing data stays unknown.
Estimated API cost
Estimates use the known billing model and rate version and keep currencies separate. Check your provider invoice for actual charges.
Subscription limits and balances
Use Account Quotas to refresh supported sources or open the official usage page. Subscription windows and provider balances follow their respective accounts.

How do I check Claude Code usage and subscription limits?

In Usage & Metrics, select Claude Code and a date range to review the requests and tokens Senrelay has observed. For Claude Code's current subscription windows and reset times, run /usage in Claude Code or open its official usage page. Official Claude Code usage guide.

How do I track Codex usage, account limits, and API cost?

Filter Usage & Metrics to Codex and open Requests for observed usage. Use Read Codex quota in Account Quotas to check the locally signed-in Codex account. For actual OpenAI API charges, check the organization that pays for the API calls. Official OpenAI API usage dashboard.

Why does one request have multiple attempts?

For example, the primary provider can return 429 and a fallback provider can complete the request. The ledger shows one logical request and two attempts. Expand it to check the failure, actual model, token counts, and available cost estimates. Export the filtered attempts as CSV for a row-by-row view. See agent and provider configuration.

Frequently asked questions

Does the tracker cover every Claude Code or Codex call?

Coverage depends on authorized, parsable logs and requests that use the local route. Open Sources and pricing to check the observation sources. Missing usage stays unknown.

Are estimated costs the charges on my subscription?

Estimated costs use observed tokens and the effective rate. Subscription quotas, actual API charges, and provider balances come from their own sources.

Which third-party balances or budgets can I check?

Supported sources include authorized DeepSeek and Moonshot Kimi balances and an OpenRouter key budget. OpenRouter account balance needs an authorized management key. Each lookup shows its source and observation time.
