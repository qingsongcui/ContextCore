联系 Senrelay — 讨论、缺陷与安全报告

没有客服电话，也没有公开邮箱。提问用 GitHub Discussions，缺陷用 Issues，安全问题走私下漏洞报告。回复是尽力而为，没有 SLA。

更新于 2026-11-23 · Qingsong Cui（George O'Nair）

联系渠道

  • 产品问题与用法：GitHub Discussions
  • 缺陷与复现：GitHub Issues
  • 安全漏洞：安全页上的 GitHub 私下报告，不要把利用细节发到公开 Issue
  • 公开动态：X @George_ONair

安装步骤仍以 运行指南 为准。源码与许可在 qingsongcui/ContextCore。

报缺陷时请带上

  • Senrelay 版本（当前公开包是 v1.0.0-beta.6）和 macOS 版本
  • 界面：工作台、CLI 还是某个宿主（Claude Code / Codex / Cursor 等）
  • 可公开的最小复现步骤；不要粘贴密钥、私人对话或数据库导出

常见问题

有没有电子邮件地址？

不在本站公布邮箱。公开讨论请用 GitHub Discussions，避免把凭据发到邮件或 Issue。

多久会回复？

个人维护，没有承诺时限。安全报告优先于功能请求。

商业合作怎么找？

先开一条 GitHub Discussion 说明来意，或通过 X 发一条不涉密的简介。没有销售团队。

Channels

  • Product questions: GitHub Discussions
  • Bugs: GitHub Issues
  • Security: private reporting on the security page — do not post exploit details in a public issue
  • Public updates: X @George_ONair

Install steps stay on the setup guide. Source and license: qingsongcui/ContextCore.

When you file a bug

  • Senrelay version (current public ZIP is v1.0.0-beta.6) and macOS version
  • Surface: workbench, CLI, or which host (Claude Code / Codex / Cursor, and so on)
  • Minimal public reproduction steps. Do not paste secrets, private chats or database exports

Frequently asked questions

Is there an email address?

This site does not publish an inbox. Use GitHub Discussions for public questions. Do not send credentials to Issues.

How fast do you reply?

This is a personally maintained project with no SLA. Security reports come before feature requests.

How do I reach you about a partnership?

Open a GitHub Discussion or send a non-sensitive note on X. There is no sales team.
