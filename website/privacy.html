Senrelay 隐私说明 — 网站与本机应用

本页分开说明两件事：静态官网 senrelay.com，以及你 Mac 上的本机 Senrelay 应用。网站无账号；应用不上传会话或代码。

更新于 2026-11-23 · Qingsong Cui（George O'Nair）

本网站（senrelay.com）

官网是静态站点，托管在 GitHub Pages。没有用户账号、没有自建后端、没有邮件订阅表单，我们也不会在站点上出售个人数据。

部署到 senrelay.com 时，页面可能加载 Microsoft Clarity（页面分析、热力图、会话回放）。Clarity 由 Microsoft 运营，适用 Microsoft 隐私声明。预览构建（未设置 CLARITY_ID）不会注入该脚本。

GitHub Pages 会记录常规访问日志，适用 GitHub 隐私声明。macOS 安装包从 GitHub Releases 下载，下载记录同样由 GitHub 处理。

本机应用

Senrelay 应用把 HTTP/MCP 服务绑在 127.0.0.1:8420。会话索引、工作任务、记忆与配置快照存在 ~/Library/Application Support/ContextCore（目录 0700，数据库 0600）。API Key 进入 macOS 钥匙串。应用本身不把对话或代码上传到我们的服务器——我们没有这样的服务器。

你在 Claude Code、Codex 等宿主里调用的模型，仍会把你发给该供应商的内容送到该供应商。那是你自己的供应商账号，不是 Senrelay 云。

安装与数据边界见 运行指南。

你能做什么

  • 用浏览器拦截或扩展阻止 Clarity；不影响本机应用。
  • 卸载应用并删除 ~/Library/Application Support/ContextCore 以移除本机数据。这是应用层删除，不是取证级擦除承诺。
  • 隐私相关问题走 联系页 的 GitHub Discussions；安全漏洞走 安全页 的私下报告。

常见问题

官网会不会保存我的对话？

不会。官网是静态页面，看不到你的本机会话。对话只存在你的 Mac 与你使用的编程助手里。

为什么还要用 Clarity？

用来看哪些页面有人打开、从哪里离开。它不连接本机应用。若未设置部署变量，构建产物里不会出现 Clarity 脚本。

你们卖数据吗？

不卖。本站没有付费分析转售，也没有广告网络。

This website (senrelay.com)

The site is static and hosted on GitHub Pages. There are no user accounts, no first-party backend, and no newsletter form. We do not sell personal data from this site.

When deployed at senrelay.com, pages may load Microsoft Clarity (page analytics, heatmaps, session replay). Clarity is operated by Microsoft under the Microsoft Privacy Statement. Preview builds without CLARITY_ID do not inject the script.

GitHub Pages keeps ordinary access logs under the GitHub Privacy Statement. The macOS ZIP is served from GitHub Releases; GitHub handles those download logs.

The local app

The Senrelay app binds HTTP/MCP to 127.0.0.1:8420. Session indexes, working tasks, memories and config snapshots live in ~/Library/Application Support/ContextCore (directory mode 0700, database mode 0600). API keys go to the macOS Keychain. The app does not upload chats or code to a Senrelay server — there is no such server.

Model calls you make inside Claude Code, Codex or other hosts still go to your provider. That is your account, not a Senrelay cloud.

See the setup guide for install and data boundaries.

What you can do

  • Block Clarity with a browser extension. That does not affect the local app.
  • Uninstall the app and delete ~/Library/Application Support/ContextCore to remove application data. That is application-level deletion, not a forensic-erasure claim.
  • Privacy questions go to GitHub Discussions. Security issues go through the security page.

Frequently asked questions

Does the website store my chats?

No. The site is static and cannot see local sessions. Chats stay on your Mac and in the coding assistants you use.

Why is Clarity used at all?

To see which pages are opened and where people leave. It is not connected to the local app. Builds without the deployment variable do not include the script.

Do you sell data?

No. There is no paid analytics resale and no ad network on this site.
