01 / THE REASON把上下文，留在项目里

把时间留给推进，
不是重讲背景。

架构刚敲定，代码写到一半，
换个 Agent，还得从头交代？

Senrelay（续境）把跨 Agent 对话接力、伴生自动记忆与多宿主配置管理融进同一座本机工作台。日常对话中，伴生 MCP 与 Skills 会采集带原文出处的结构化记忆（附简短 💡 回执）；切换到新助手只需输入 /contextcore 或说一句「接力」，即可自动盘点近期对话记录、选定目标会话或附带新指令直接续做。

看看它如何工作 ↗
[ 01 ]

服务商与模型切换

顶栏秒切宿主，一键填入预设服务商、测试端点延迟，一键启用并跨宿主同步 MCP 与 Skills，支持按需导入本机已有配置。

[ 02 ]

伴生隐式自动记忆

对话过程中由伴生 MCP 与 Skills 采集带原话出处的结构化记忆并给出简短 💡 回执，同时支持手工整理与多格式知识文档导入。

[ 03 ]

一句话跨 Agent 项目接力

在新 Agent 输入 /contextcore 或说「接力」，自动列出近期对话记录候选；只选序号先汇报摘要待命，附带具体任务则直接续做。

覆盖核心多 Agent 协同场景

  • 跨宿主编程接力在 Claude Code 写完后端接口，切到 Cursor 或 Codex 直接续上改动边界与测试进度。
  • 深度调研与架构规划带着多轮讨论的资料来源、已排除方案与约束条件，换个模型继续推演。
  • 伴生隐式记忆沉淀对话中自动捕获编码规范、偏好语气与踩坑教训，下一次会话自动生效。
  • 多助手配置一处统管服务商、MCP、Skills 与系统提示词一键切换与同步，自动留存安全快照，遇到外部手动修改冲突时弹窗核对差异。

07 / A FEW GOOD QUESTIONS

你可能还想知道。

关于接棒、数据，
以及现在可以做什么。

跨 Agent「对话接力」具体是怎么触发和工作的？+

当你打开一个新的 Agent（如从 Claude Code 切到 Cursor、Codex、Antigravity、OMP 或 OpenCode）并输入 /contextcore 或说出「接力 / 接着做 / relay」指令时，伴生 Skill 与本机服务会自动列出近期的跨宿主对话记录候选（含序号、来源 Agent、所属项目、会话标题与摘要）。如果你只回复序号，新 Agent 会加载该会话的接力上下文（must_not_execute=true）并先汇报摘要、等待你的下一句指令；如果你在选择序号的同时附带了具体任务（例如“选 1，把单元测试补齐”），新 Agent 会结合上下文直接开始续做。

隐式自动记忆是如何自动触发的？+

无需手动点击“保存笔记”。在你与 Agent 对话过程中，当伴生 MCP 与记忆 Skill 识别到架构决定、用户偏好、关键约束、进度节点或踩坑经验时，会直接捕获带原文出处的结构化记忆并给出简短 💡 回执；遇到与既有规则冲突时自动进入「待确认」分歧箱，你也可以随时在项目工作台手动编辑、置顶 📌 核心规则或导入文档。

可以同步或导入哪些本机配置？+

支持范围按宿主与操作区分。工作台提供顶栏多宿主切换、预设服务商一键填入、预览确认后切换、端点延迟测速、模型映射与 MCP / Skills / 提示词跨宿主同步能力，并支持本机已有配置文件与扩展目录受支持格式的导入与导出及环境变量覆盖冲突检测。

改一位助手的配置，会自动影响其他助手吗？+

不会擅自覆盖。你可以针对单个宿主独立启用服务商或调整规则，也可以显式勾选多个宿主一键同步共享的 MCP 工具、Skills 与提示词。每次应用前均可预览变更差异，并自动保留回滚快照。

数据与 API Key 是否安全地保存在本机？+

所有聊天记录索引、项目记忆、知识文档与配置快照均存储在你的 Mac 本机 SQLite 数据库（文件权限 0600），API Key 独立保存在 macOS 系统钥匙串中。配置导出与分享包默认剔除托管密钥。

现在如何安装、启动并体验完整工作台？+

可通过 Homebrew 执行 brew install --cask qingsongcui/tap/senrelay 或前往 GitHub Releases 下载免费开源的 Senrelay-macOS.zip（MIT 协议），也可按下方「本地运行指南」从源码启动本机服务与浏览器工作台（默认端口 127.0.0.1:8420 / 18420）。注意：请勿执行 pip install contextcore，PyPI 上同名包为无关第三方项目。
